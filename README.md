# HostelHub
Hostel management: warden/admin, student and guard portals. React + Vite client, Express + Mongoose server, MongoDB Atlas.

- Local testing (Termux/Android): TESTING.md
- Production deployment: DEPLOYMENT.md
- Staff accounts: `npm run create-warden` / `npm run create-user -- GUARD ...` (server). DB check: `npm run check-db`.

Not built: Reports, Settings, complaint attachments, seed script, email-based forgot password.
Status: syntax/bundle/route cross-checks only. Not run against MongoDB, not production-tested.
